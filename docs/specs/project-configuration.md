# KOS Project Configuration

This specification is superseded by [Workflow Catalog](workflow-catalog.md). KOS now owns shared workflow definitions, instructions, and templates in its central SQLite database; target repositories no longer provide authoritative `.kos` workflow configuration.

The former project-owned bundle contract remains available in Git history for completed bootstrap-task traceability and is not normative.
